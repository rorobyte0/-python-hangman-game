Python Hangman Game
A simple word-guessing game developed using Python.
Features
• Random word selection
• Letter guessing
• Limited attempts
• Tracking previously guessed letters
• ASCII Hangman drawings showing incorrect guesses
• Win and lose conditions
Technologies
• Python
• Random module
• Lists, loops, and conditional statements
How to Run
1. Make sure Python is installed.
2. Run main.py.
3. Enter letters to guess the hidden word before running out of attempts.
